# 成都地铁步行覆盖

成都地铁线路、站点与步行可达覆盖工具。

## 下载

请在 [Releases](../../releases) 页面下载桌面版。当前提供 macOS Apple Silicon（arm64）版本；后续版本可继续添加 Intel Mac、Windows 和 Linux 构建。

## 功能

- OpenStreetMap 快照线路与站点
- 直线距离圆形覆盖区
- 本地步行路网等时圈
- 地图自由选点
- 可调步行时间、覆盖半径和透明度
- 不依赖云端步行 API 或 Docker

首次启动会解压约 200 MB 成都步行路网数据，地图底图需要联网加载。

## macOS 首次打开

当前包未进行 Apple 公证签名。如果系统阻止打开，请在“系统设置 → 隐私与安全性”中允许该应用。
